# راه‌اندازی فروشگاه با JSON Server

## فایل‌ها
- `index.html`: صفحه اصلی موجود
- `js/kheilisabz.js`: منطق فرانت‌اند و ارتباط API
- `css/kheilisabz.css` و `style.css`: استایل ارسال‌شده
- `db.json`: داده اولیه محصولات و بخش‌های صفحه

## اجرا
1. Node.js را نصب داشته باشید.
2. ترمینال را در پوشه همین پروژه باز کنید.
3. اجرا کنید: `npm install`
4. اجرا کنید: `npm run server`
5. در ترمینال دیگری سایت را با افزونه Live Server در VS Code باز کنید. بهتر است صفحه از طریق `http://127.0.0.1:5500/index.html` باز شود، نه با `file://`.

JSON Server در `http://localhost:3000` اجرا می‌شود. مسیرهای اصلی: `/products`, `/cart`, `/slides`, `/brands`, `/grades`, `/banners`, `/categories`, `/orders`.

## نکته‌ها
- محصولات، پیشنهادها، سبد خرید، اسلایدها، مجموعه‌ها، پایه‌ها، بنرها و دسته‌بندی‌ها از API خوانده می‌شوند.
- سبد خرید و سفارش آزمایشی در `db.json` ذخیره می‌شوند. پرداخت واقعی، احراز هویت و ثبت‌نام واقعی پیاده‌سازی نشده‌اند؛ برای آن‌ها backend امن و سرویس پرداخت لازم است.
- فایل‌های تصویری `images/` در فایل‌های ارسالی موجود نبودند. پوشه `images` پروژه اصلی‌ات را در کنار `index.html` کپی کن تا تصاویر نمایش داده شوند.
- فایل CSS ارسالی در هر دو مسیر `style.css` و `css/kheilisabz.css` قرار داده شده تا لینک‌های HTML حفظ شوند. اگر `style.css` اصلی پروژه‌ات متفاوت بوده، نسخه اصلی آن را جایگزین کن.
- برای تغییر آدرس سرور، مقدار `API` در ابتدای `js/kheilisabz.js` را تغییر بده.
